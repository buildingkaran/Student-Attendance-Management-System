Node.js + Express

Q1. REST Server & Routing

Non-blocking, event-driven web server listening on port 3000. Features modular routing: /api/students, /api/faculty, /api/attendance, and /api/dashboard with centralized JSON error handling and input validation.

app.use(express.json());
app.use('/api/attendance', attendanceRoutes);
MongoDB Atlas

Q2. Data Modeling & Queries

Mongoose document schemas for Student, Faculty, and Attendance. Implements compound unique indexing { studentRollNo: 1, subject: 1, date: 1 } to prevent duplicate records, and MongoDB Aggregation Pipelines to compute percentages.

attendanceSchema.index({ studentRollNo: 1, subject: 1, date: 1 }, { unique: true });
fs & Yargs

Q3. Audit Logs & CLI

The built-in fs.appendFile() asynchronously writes timestamped audit lines to logs/attendance.log. The cli.js script uses Yargs to parse terminal arguments for adding students, marking attendance, and outputting formatted ASCII reports.

node cli.js stats --roll=24107030
node cli.js mark --roll=24107030 --status=Present
Git / Jenkins / Maven

Q4. CI/CD & Build Management

Source code versioned with Git. Declarative Jenkinsfile automates testing (npm test) and image builds. Maven is documented as a Java-oriented build tool: npm manages Node dependencies, while Maven handles enterprise integration (e.g. Java ERP authentication microservices).

pipeline { agent any; stages { stage('Test') { steps { sh 'npm test' } } } }
Docker

Q5. Containerization & Ports

Multi-stage lightweight Dockerfile based on node:20-alpine. Port forwarding maps external host port 8080 to internal container port 3000 (-p 8080:3000) via docker-compose.yml.

docker build -t attendance-app .
docker run -d -p 8080:3000 attendance-app
